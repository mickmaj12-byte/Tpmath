# TPMath - Browser-Based Gaming Platform

🎮 TPMath is a modern, sleek gaming platform that lets you play trending online games directly in your browser. No downloads, no installations - just pure gaming fun!

## Features

✨ **Browse Games** - Explore a curated collection of IO Games and Trending titles
🔍 **Smart Search** - Find your favorite games instantly
⭐ **Rating System** - See how other players rate each game
❤️ **Favorites** - Save your favorite games for quick access
📱 **Responsive Design** - Play on desktop, tablet, or mobile
🎨 **Modern UI** - Beautiful dark theme with smooth animations

## Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling
- **Lucide React** - Icons

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/mickmaj12-byte/Tpmath.git
cd Tpmath

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will open at `http://localhost:3000`

### Build for Production

```bash
npm run build
```

## Deployment on Vercel

TPMath is optimized for **Vercel** deployment (completely free!):

1. **Push to GitHub** (already done ✓)
2. **Go to [Vercel.com](https://vercel.com)** and sign in with GitHub
3. **Click "New Project"** and select this repository
4. **Click "Deploy"** - Vercel will automatically detect it's a React/Vite app
5. **Your site is live!** You'll get a free URL like `tpmath.vercel.app`

### Why Vercel?
- ✅ Free tier with unlimited deployments
- ✅ Automatic deployments on every GitHub push
- ✅ Lightning-fast global CDN
- ✅ Zero configuration needed
- ✅ Perfect for React apps
